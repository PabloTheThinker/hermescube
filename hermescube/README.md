# `hermescube` package

Public API is exported from `__init__.py` (`CubeFile`, `HARQueryEngine`, `CubeMemoryProvider`, …).

**Where to edit what:** see [docs/CODEMAP.md](../docs/CODEMAP.md).

Quick orientation:

- **I/O & retrieval** — `cube.py`, `har.py`, `hrr.py`, `embed.py`
- **Hermes socket** — `provider.py` + `tools_recall.py` + `manage*.py`
- **Governance** — `cuboasis.py`, `memory_gate.py`, `cubewave.py`
- **Fleet** — `hive.py`, `hq.py`, `interview.py`
- **Dream** — `dream.py`, `dream_circle.py`, `manage_dream.py`
